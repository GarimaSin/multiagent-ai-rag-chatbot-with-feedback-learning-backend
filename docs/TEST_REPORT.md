# Validation report — 14 September 2026

## Multi-Agent AI RAG Chatbot with Feedback Learning

This report covers the renamed source archives, not a deployed production system.
Tests used synthetic data, separate disposable user/reviewer keys, a temporary
SQLite database, the extractive demo provider and mocked provider responses.
No paid model call or private user document was used.

## Naming-specific checks

The backend regression tests cover the exact display name, filesystem-safe slug,
API title, answer-system-prompt identity, explicit database connection overrides,
metric prefixes, package metadata, bundled OpenAPI title and frontend Compose path.

The frontend checks cover shared branding constants, static title/metadata, favicon,
package/lockfile consistency and imports used by the UI and local server. Offline
browser checks verify that the full name is visible and not horizontally clipped
in the sidebar, login or assistant labels, including narrow mobile viewports.

## Functional regression checks

The existing backend suite continues to cover authentication, private data isolation,
retrieval, citations, abstention, streaming, request replay, failed/truncated provider
responses, feedback consent, independent review, evidence checks and withdrawal of
learned knowledge when the source is removed.

The separate HTTP smoke flow verified authentication, worker ingestion, streamed
answers with citations, idempotent replay, private conversations, consented correction
approval and indexing, source withdrawal, and conversation deletion. Its displayed
first-token timing is a single local extractive-demo observation, not a live-model
benchmark or production latency guarantee.

## Not executed in this rename pass

Live model calls, PostgreSQL integration tests, Docker image builds, Kubernetes
deployment and full browser-to-live-API testing were not executed. Compose and
Kubernetes files were checked statically only. Offline browser tests and real HTTP
service tests were executed separately; neither substitutes for live browser E2E.
The CI matrix on other Python versions and production load/failover testing were
not run. Existing databases and deployments were not migrated or modified.

## Release integrity

Both archives include `MANIFEST.sha256` covering every packaged file except the
manifest itself. Updated archives were checked for remaining former-name text and
filenames, archive integrity and checksum consistency. No credentials, local
databases, virtual environments, installed dependencies or generated bytecode are
packaged. Keep existing configuration/database connections when upgrading; see
`docs/RENAMING.md`.
